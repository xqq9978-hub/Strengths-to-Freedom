# V1.1 五屏映射与交付

V0.4.0 使用 V1.1 视觉模板并由 `scripts/render_report.py` 注入 `references/data-contract.md` 所定义的统一数据。愿景、起点、四维与优势、三条未来路径、30天/90天/一年行动计划，以及收入 iframe 均从同一报告 JSON 获取；不是简单替换旧样稿中的一个 JSON。重要细节、证据、假设与限制放在各屏可展开处，不添加第六主板块。

保留深色背景、五屏布局、动效和路径切换；收入不完整时用不按金额比例绘制的分岔路径，未知不插值。愿景优先、继续/调整/暂停仅为页面临时交互，不写回文件；重开恢复原始数据。AI推荐和用户选择独立；改变愿景不会自动重新测算收入。HTML 不提供自动同步到 Skill 的反向保存或跨设备同步。

请按访谈真实记录构造 JSON；样例仅测试用。先生成文件再实际打开验收；无法运行、验收或交付文件时说明具体限制并标记未完成，不得以文字或 JSON 替代最终 HTML，也不得冒充已生成。浏览器中可用，无需联网；来源链接需要网络才能打开。参照包中的使用说明和测试脚本。
