# 进化路线：30天 / 90天 / 1年

## 方法与衔接
参考Human 3.0的跨维度观察、知识/经验/技能区分及解决当下限制的思路：从01目标、02约束、03具体经历和04所选路径找最重要的待验证限制→确定假设→选择低风险行动→获得反馈→调整。跨维影响需要本人经历支持。阶段名称仅作有证据的暂定描述；30天/90天/1年不是Human 3.0原始阶段、不是必须逐一晋级的承诺。稳定有效时可巩固而非增加任务，未知时先观察而非贴失调标签。

## 为每条路准备相互区别的计划
默认A/B/C各保留一套，按用户选择优先展示一套；未选择则推荐仅为建议，可展示三套简版，不暗示用户必须全做。每套写路径对应假设、个人证据及约束，按“如果出现[具体情境/障碍]，就做[可执行动作]”帮助启动；不要捏造用户的日程、联系人或预算。每个节点的任务应与路径对象、交付物、反馈不同，而非仅更换标题。

- **30天：一次小范围验证。** 指定对象与场景、具体动作、可交付物、反馈与最小时间；未有结果写待验证，不承诺获客或加薪。
- **90天：复盘是否继续。** 在30天反馈基础上，注明真实记录、假设支持/不支持/仍不确定、继续/调整/暂停的事先标准。无反馈并不自动等于无需求。结果发生前decision=pending。
- **1年：积累与生活复盘。** 检查技能是否可复用、实际机会/收入是否可核对、投入及生活边界是否可持续，并对照01的生活目标决定继续/调整/暂停；可能无法达成也可复盘，不写“1年必然稳定收入”。

每项写：任务及对象、步骤、产物、预计时间与估时依据、预算或未知、反馈来源与观察窗口、完成标准、风险/边界、未达成时缩小/延期/暂停。清楚区分单次工时与该节点累计工时，避免30、90天重复相加；已知周可用时间要按期间实际校验，未知时只给规划估时并标容量待确认。对未来门槛由AI建议时标为假设，非官方阈值或成功概率。计划不要求未经授权联系、发布、辞职或投资。

## 风格示例（仅演示格式，不是任何用户事实）
假设：一次现场工作样本能帮助判断本人是否喜欢某类交付。
30天：若工作中有合适且可分享的任务，脱敏整理一页方案（预计1–2小时，容量待确认），征得同意后请熟悉任务的人反馈“哪里可用、哪里不清楚”；无人可问则只整理并标无反馈。
90天：如得到具体反馈且本人愿意，选一个反馈修改后再试；若没有场景，调整获取反馈的方式或暂停，不判定成功。
1年：以真实记录核对是否形成重复使用、真实机会与可持续节奏；尚无数据则记未知并重选小实验。
