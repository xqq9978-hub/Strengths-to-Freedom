# 测试记录

在本次开发环境中，使用 Chromium 和 Playwright、两组虚构数据完成以下代表性测试：
- 五屏基本导航、愿景优先切换、起点与优势证据展开。
- 收入图与 A/B/C 路径双向同步，切换路线后行动计划同步；30/90/365 节点及临时复盘按钮。
- 未知收入不补零或插值，完整数字测试能显示单位及曲线；统一基线和市场证据缺项校验。
- 无优势数据、HTML 脚本转义、移动端 390×844、减少动效；无旧案例字样残留于测试页面可见文本。

本测试不能证明所有浏览器与所有超长内容都完美兼容，也不能验证外部数据、访谈推论、市场来源真实性、财务计算的正确性。后续真实使用需根据具体数据和宿主条件再次验收。所有样例均为虚构，完整数字样例中 M1 链接是专为测试构造的占位，并非真实市场依据。
