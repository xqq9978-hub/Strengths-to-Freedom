# V0.3.7 更新与检查

本次改善通用Skill、四维建议数据和HTML绑定，不只修改案例文案。

- 修正漏改的阅读路线：01收入可能→02认识自己→03变现与行动；收入台阶仅在第一部分内展开，没有第二个02。
- 借鉴用户参考包的关键变量追问、日常生活检验和有退出条件的小实验；不沿用两轮报告、名人圆桌或固定措辞。
- 每维增加coaching：具体判断、当前卡点、一个动作、观察信号、调整条件与Human 3.0概念应用。发现优先巩固，探索优先检验，未知先观察；不把四维变成四项额外作业。
- 主文说具体行为，例如朋友临时约时有时不好意思拒绝；工作消息打断休息另有证据，不能拼成人格判断。理论与详细依据折叠。
- 收入曲线、“全部点亮”、台阶同尺度、三路行动和未知处理保留；案例收入及三套原行动不变。

已执行：21项原结构/异常用例；6类HTML生成与内外脚本语法及转义；6类人物内容/地图/收入路径联动；读者内容重复与容量回归；四维层级阶段几何、三部分结构、生活数据不足及引用负面用例；新增四维建议来源、阶段/动作冲突、失效引用、同一泛泛建议和三步导航检查；新增模拟DOM四维切换、各自建议/反馈与文本转义检查。收入公式、台阶、全部点亮沿用规则并复查。

脚本与模拟DOM不能判断建议是否在真实生活里奏效，也不等于真实浏览器视觉验收。手写访谈对照案例只是测试设计与人工审读，不是独立模型运行结果。豆包导入、实际访谈、语音与宿主运行仍未实测。系统quick_validate已尝试，因缺少PyYAML不能运行，不称通过。

投影仪案例仍是原虚构访谈，没有新增人物回答。HCOACH是新增建议假设；level/phase和收入模型未改。第三种独立生活方向及五年生活画面仍保留未知，不以改文案掩盖证据不足。
