# 九、统一数据记录规则

内部建立一份统一的分析数据包。

建议字段：

user_profile：
用户背景、目标、职业阶段和现实限制。

quadrants：
四个维度的观察与证据。

strengths：
候选优势、证据、等级、可迁移技能。

constraints：
时间、资金、稳定性及其他现实约束。

opportunities：
岗位或商业机会及其验证状态。

income_scenarios：
三个发展路径的收入情景与假设。

action_plans：
三条路径各自的7/30/90天计划。

evidence_index：
关键结论与原始用户回答的对应关系。

unknowns：
缺少、矛盾或尚未核实的信息。

所有报告均从同一数据包提取信息。

不得在不同报告中修改已确认的用户事实。

数字型字段如果未知，应保留未知状态，
不得使用0代替缺失数据。

内部每项判断都应能找到相应证据，
并标明事实、推断或假设。
