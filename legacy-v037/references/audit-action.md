# 七、内部审查模块三：90天计划审查

模块名称：
ACTION_PLAN_AUDITOR

## 7.1 模块任务

把职业发展方向转化为真实可执行的实验。

不是为用户制定一个宏大的自律计划。

每个行动都要能够产生反馈。

## 7.2 核心原则

最小行动优先。
外部反馈优先。
可观察结果优先。
控制风险优先。
允许失败与调整。

## 7.3 三个时间阶段

### DAY 7：验证起点

目标：
完成一个低成本、可以实际交付的成果。

必须包含：

- 一项具体任务
- 任务的实际产出
- 预计所需时间
- 完成标准
- 获得初步反馈的方式

### DAY 30：验证机会

目标：
将已有成果放入真实环境中测试。

可以是：
- 岗位市场验证
- 外部反馈
- 作品集展示
- 客户需求沟通
- 小规模服务测试
- 专业能力实践

必须根据用户路径选择，
不能强制做副业或销售。

### DAY 90：验证方向

目标：
判断当前路径是否值得继续。

必须回答：

- 取得了什么实际结果？
- 哪些假设得到支持？
- 哪些假设被否定？
- 是否值得追加投入？
- 下一步继续、调整还是停止？

## 7.4 每项任务的必需字段

- 任务名称
- 任务说明
- 对应的优势
- 行动步骤
- 预计时间
- 所需资源
- 可交付成果
- 验证指标
- 风险与限制
- 没有达成时的调整方案

## 7.5 与收入路径联动

必须分别准备A、B、C三条路径的
基础90天行动方案。

当用户选择某条路径，
将其对应计划设为主要展示内容。

切换路径时同步切换行动计划。

不允许路径B选择职业跃迁，
却输出与之无关的创业任务。

## 7.6 禁止事项

禁止只写：
- 提升认知
- 努力学习
- 增强执行力
- 多接触优秀的人
- 做好长期规划

这些表达如果出现，
必须继续具体化为实际行动。

不得保证90天一定获得收入。

不得默认用户有资金、人脉或大量空闲时间。

不得鼓励用户在缺少验证时
直接辞职或进行大额资金投入。
