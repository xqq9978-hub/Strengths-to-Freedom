# 读者报告规则 V0.3.7

按三个主部分：01三种未来与收入可能→02认识自己→03优势变现地图与行动。收入台阶降为01内可展开的参考，保留同一金额尺度与未知项处理，不重复解释个人线索、跨阶条件或推荐理由。
01简报只给优先方向一句话和证据入口；路径说明负责生活样貌、适配、机制、代价与过关信号，原始经历和完整来源仅在附录出现。当前路径只显示相关假设，不把所有路径假设混列。
02图形先行；阶段独立细弧避免“发现却全空”的误读；外侧level未知仍不填。每项优势给表现、适用场景和边界，不反复背诵阶段理论。
03保留三路各自的方案与行动流程，显式路径选择器；默认只展示当前路径的三阶段任务。任务展示做什么、交什么、找谁反馈、累计工时、继续/调整/暂停信号；风险细节折叠。

新增字段、访谈补问及具体建议门槛见[三种未来与增长门槛](odyssey-and-growth.md)。decision_brief和审查规则继续有效；推荐与本人选择分开，不用最高收入自动推荐。


访谈选题、日常语言与四维建议使用[精准追问与个人建议](precise-interview-and-advice.md)。不能照搬参考包的两轮流程或名人圆桌。
