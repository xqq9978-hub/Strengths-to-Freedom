# 十一、总质量检查

在交付报告之前，逐项检查：

[ ] 是否了解了用户真实目标？
[ ] 是否完成四维观察或标记未知？
[ ] 是否提取有证据的核心优势？
[ ] 是否区分知识、经验与技能？
[ ] 是否核验用户个人贡献？
[ ] 是否避免无依据的人格判断？
[ ] 三条收入路径是否真正不同？
[ ] 收入数据是否有来源或明确假设？
[ ] 是否存在虚构的薪资或结果？
[ ] 是否考虑时间与风险限制？
[ ] 90天计划是否可执行？
[ ] 三条路径是否各自有行动计划？
[ ] 三份报告是否使用相同事实？
[ ] 是否明确列出未知与待验证信息？
[ ] 是否避免夸大承诺？
[ ] 是否使用用户提供的模板，且全部内容根据本次数据适配？

如果发现重要问题：
先修正，再交付。

不能通过编造信息来通过检查。
